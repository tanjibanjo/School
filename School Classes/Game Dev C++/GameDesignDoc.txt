DESCRIPTION
-----------

the game is a horde wave fps. it is set in a post-apocalyptic, overgrown cityscape area. you are armed with a basic pistol, and through the game will be able to access a shotgun as well (maybe more, but for now that's all i can guarantee). you use these to defend yourself from grotesque monsters that are coming to kill you.

you are a journalist - a truth seeker. you are in the no man's land. there are people that live here and have nowhere to go. there are stories to tell. your job is to type and send off these stories while defending yourself. the gameplay is a balance of ammo and time management using what little there is to type as fast as you can. learn more about the zone and it's inhabitants throughout the game. don't die.
